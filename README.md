# POA Digital — Demo

## Correr en tu computadora
1. Instalá Node.js (18 o superior) si no lo tenés: https://nodejs.org
2. Abrí una terminal en esta carpeta y ejecutá:
   npm install
   npm run dev
3. Abrí la URL que te muestra la terminal (normalmente http://localhost:5173)

## Publicar en internet (sin Lovable, más rápido)
La forma más directa: arrastrar esta carpeta a https://app.netlify.com/drop
o conectar el repositorio a https://vercel.com — ambos detectan Vite solos.

## Subir a GitHub (para conectar con Lovable)
git init
git add .
git commit -m "POA Digital demo"
Luego creá un repositorio vacío en GitHub y seguí las instrucciones
para "push an existing repository from the command line".
